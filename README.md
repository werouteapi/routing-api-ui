# Routing API - Developer UI

Interactive web-based forms for developers to test and integrate with the Routing API.

## Features

- 🎯 **Payment Routing Simulator** - Test routing logic in real-time
- 🔐 **Compliance Check Tool** - Verify sanctions and compliance status
- 💳 **Transaction Builder** - Build and send test transactions
- 📊 **Response Inspector** - View detailed API responses
- 🌍 **Multi-Currency Support** - Test payments in any currency
- 🧪 **Webhook Tester** - Simulate and test webhook events

## Getting Started

```bash
npm install
npm run dev
```

Visit: http://localhost:3000

## Integration

Use the forms to:
1. Generate test API keys
2. Build sample requests
3. Copy code snippets for your SDK
4. Test webhooks locally
